# Release notes: 0.1.0-staging (2026-11-23)

This repository is a clean public-release copy of the development repository `wholecell` (private, full history).
It was staged (release commit ad93956f54ef48122afc1bcd7ee9e8ec33b49113, "0.1.0-staging") from development `main` at **e5dda5c** (`e5dda5cf36b2bd34647b71b6b6f068954cb54ecf`) with a fresh git
history. The two paper builds were made from development commit **0a3ba79**; `git diff 0a3ba79 e5dda5c` outside
`applications/` is docs-only (the two freeze acceptance addenda), so the pipeline code here is the paper-build code
plus the release edits listed below. Pins: `config/paper_builds.yaml`.

## Contents
| Path | What |
|---|---|
| `wholecell/` | the pipeline package (stages, config loader, build discipline, export) |
| `plugins/jurkat/`, `plugins/yeast/` | cell plugins; `plugins/yeast/engine/` = vendored yeast engine (G. Magnusson; `PORT_PATCHES.md`) |
| `config/` | cell configs (`cells/jurkat.yaml`, `cells/yeast.yaml` = the paper cells; `cells/testcell.yaml`; reference configs, see below), geometry rules, subsets, validation vocabulary, site template, `paper_builds.yaml` |
| `Snakefile`, `workflow/` | the build workflow (Snakemake 8.30) |
| `toolkits/` | geometry toolkits (analytic, EM) and the SEC-MS toolkit |
| `scripts/` | build launchers and checks used for the paper builds; `scripts/dev/` = development / unification checks |
| `tests/` | test scripts (`tests/test_*.py`, run each with `PYTHONHASHSEED=0 python tests/test_X.py`) and `tests/data/` |
| `envs/` | environment exports (core, orchestration, yeast engine) |
| `docs/` | documentation; `docs/reference/history/` and `docs/unification_criteria/` are frozen records (md5s cited in the freeze records; not edited) |
| `data_manifest.tsv`, `docs/data_inputs.md` | every input of the two paper builds: source, licence, size, checksum, deposit |

## Changes made for the release (no change of build behaviour)
1. **Site template.** `config/site.yaml` is a template with `<...>` placeholders (it held the development machine's
   paths). Env overrides `WHOLECELL_SITE`, `WHOLECELL_DATA_ROOT`, `WHOLECELL_RESULTS_ROOT`, `WHOLECELL_GEOM_ROOT`,
   `WHOLECELL_YEAST_ROOT` (unchanged), plus new optional `afdb_root` / `WHOLECELL_AFDB_ROOT`.
2. **New placeholder `{afdb_root}`** (`wholecell/config.py`). The only absolute path in a cell config,
   `jurkat.yaml frozen_inputs.lib_afdb_human_tar.path`, is now `{afdb_root}/UP000005640_9606_HUMAN_v6.tar` (same file,
   same md5). `{yeast_root}` was already a placeholder; it stays optional (unset = placeholder left unresolved, inputs
   reported MISSING by the frozen check; only the yeast configs use it).
3. **Hidden absolute paths in code.** `wholecell/library/topology.py` read two reference tables from a hard-coded
   development path; they are now read under the site `data_root` (same files; listed as hidden inputs in
   `docs/data_inputs.md`). `tests/test_inventory_freeze_e2e.py` finds its upstream build under `results_root` (env
   `WHOLECELL_E2E_UPSTREAM` overrides). `plugins/yeast/repro/seedspread_x5.py` reads `{yeast_root}/runs` from the site.
   `toolkits/analytic/yeast_stub.py` docstring and `plugins/jurkat/data/preplaced/RIBO80S_channel_transfer.json`
   (provenance record, not read by the build) use `<yeast_root>/`, `<data_root>/`, `<results_root>/`.
4. **Vendored yeast engine** (`plugins/yeast/engine/PORT_PATCHES.md` P5, P6): author-machine paths in two one-off
   analysis scripts -> env variables; npm `"license": "ISC"` default -> `SEE LICENSE IN` the repository licence;
   the PDF dropped (above). The `# origin:` header lines of yeast- and Jurkat-derived files are unchanged; their
   "(no licence yet; local only ...)" wording is historical (`NOTICE.md`).
5. **Development / unification checks moved to `scripts/dev/`** (25 scripts; list below). Their former absolute paths
   are read from the site file through `scripts/dev/_devsite.py` (`VC` = data_root, `RESULTS` = results_root,
   `YEAST` = yeast_root, site python / snakemake). They reproduce development-time checks and need the development tree
   (legacy project tree under `data_root`, development builds under `results_root`, the yeast model tree); kept because
   the frozen criteria in `docs/unification_criteria/` cite them (by their old path `scripts/<name>`). Imports were
   adjusted (`REPO` one level up; `scripts/dev` on `sys.path` for `freeze_check.py`, `step2_combined_check.py` and two tests).
   References were updated to `scripts/dev/<name>` in `docs/stages/`, `docs/methods_secms_bound_fraction.md`,
   `PORTING_STATUS.md`, code docstrings / comments and YAML comments; the frozen records (`docs/unification_criteria/`,
   `docs/reference/history/`), the development log `docs/unification_progress.md` and the vendored test configs keep
   the old paths.
6. **Reference configs** `config/cells/b1r_*.yaml` (7 B1 reduced-benchmark overlays) moved to `config/cells/dev/`
   (`extends: ../jurkat.yaml` / `../yeast.yaml`); `scripts/dev/b1_reduced.py` updated.
7. **Test without git history.** `tests/test_localisation.py` (localisation switch test) read the pre-switch configs
   with `git show a209ad6:...`; copies are now in `tests/data/localisation_switch/` (AFDB tar path -> `{afdb_root}`).
8. **Wording.** YAML comments and SEC-MS dataset descriptor comments that called the lab SEC-MS / surface data
   "CONFIDENTIAL, local only" now say they are no longer confidential (decision 2026-11-23). The `licence:` string
   values of those frozen inputs in `jurkat.yaml` / `yeast.yaml` (and the yeast `licence.data` note) were NOT changed,
   because they are part of the hashed config: they are historical; `data_manifest.tsv` has the current licences.
9. **New files:** `README.md`, `LICENSE` (PolyForm Noncommercial 1.0.0 + Required Notice), `LICENSE-DATA` (CC BY-NC 4.0),
   `COMMERCIAL.md`, `CITATION.cff`, `NOTICE.md` (rewritten), `config/paper_builds.yaml`, `data_manifest.tsv`,
   `docs/data_inputs.md`, this file, `envs/yeast_x5.pip.txt` (package list of the yeast engine environment the yeast
   config runs its vendored scripts with), `.gitignore` additions. Doc edits: `docs/getting_started.md` (site file),
   `docs/README.md` (links), `docs/simulations.md` (pointer to wholecell-paper), `docs/ARCHITECTURE.md` (site template).
